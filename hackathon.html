One sealed challenge, forty-eight hours. Build a complete website from scratch — early-web creativity, modern craft. Solo ya team of 2–3.

The brief

Build a complete, working website from scratch in 48 hours. Not a template, not a drag-and-drop page — your own HTML, CSS and JavaScript (or any web stack you're comfortable with), shipped as a real, visitable site with a live URL.

The theme is early-web creativity paired with modern craft: the charm of the old web — personal pages, handmade layouts, playful little details, view-source friendliness — built with today's standards, responsiveness and tooling.

What to build

  • One complete website, at least 3 pages, with working navigation
  • Responsive — works on phone and desktop
  • Opens without console errors in a modern browser
  • Deployed live (GitHub Pages / Netlify / Vercel / koi bhi host) plus a public source repo
  • A short About / credits section naming your team

Requirements

  • Solo or team of 2–3
  • All code written inside the 48-hour window
  • Libraries and frameworks allowed; no-code builders allowed nahi hain
  • Content original ho, ya properly credited ho
  • Submission me repo URL aur live URL dono chahiye

Rules

  • Entry online aur free hai
  • Submissions kickoff (17 October 2026, 17:17 IST) ke baad open, 19 October 2026, 17:17 IST pe close
  • Ek team ke multiple submissions me best wala count hoga

Judging criteria

Weights suggested hain — organizers approve kar lein:

  • Design and creativity — 30%
  • Technical execution — 25%
  • Theme fit, early-web spirit — 20%
  • Responsiveness and polish — 15%
  • README and submission clarity — 10%

Timeline and prizes

  • Kickoff: 17 October 2026, 17:17 IST — brief reveal, repos initialize, building begins
  • Close: 19 October 2026, 17:17 IST — 48 hours
  • Prize pool: $400 total — 1st $160, 2nd $120, 3rd $80, 4th $40

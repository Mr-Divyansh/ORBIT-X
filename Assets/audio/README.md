# Audio Assets — ORBIT-X

This folder contains audio assets for the ORBIT-X Halloween storytelling website.

## Structure
- `music/` — Background music loops
- `ambience/` — Environmental ambient sounds (night wind, forest, distant owl)
- `ui/` — User interface sounds (button clicks, menu toggle, navigation, modal open, toggle switch)
- `interactions/` — Special interaction sounds (pumpkin click, ghost appear, bat flap, discover item)
- `transitions/` — Scene transition and storytelling sounds (scene transition, magical reveal, character appear)
- `manifest.json` — Complete asset manifest with sources and licenses
- `README.md` — This file

## Recommendation

These are full-length music samples from SoundHelix. For production, consider:
1. Trimming shorter clips for UI sounds (button clicks, toggles) using ffmpeg or an audio editor
2. Creating seamless loops for background music and ambience
3. Adding OGG versions for broader browser support
